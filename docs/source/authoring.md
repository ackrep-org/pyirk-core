# pyirk.authoring

The `pyirk.authoring` subpackage provides LLM-assisted tooling for ingesting
external knowledge sources (Lean theorem statements, LaTeX passages,
ontologies, ...) into pyirk content modules. It pairs subprocess-based
LLM calls with round-trip validation via `irkloader`.

This page is a placeholder. Documentation for the subpackage is still in
development.

For now, see `src/pyirk/authoring/` in the source tree and the design
document at `docs/design/mcp_authoring.md` (in the repository root, not
part of the built documentation site) for details.
